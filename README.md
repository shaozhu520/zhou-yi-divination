# 周易占卜 · Zhou Yi Divination

> 基于《周易》六十四卦的 AI 占卜 Skill —— 为用户的抉择、时机、趋势提供方向性参考。

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)]()
[![Skill](https://img.shields.io/badge/Skill-zhou--yi--divination-blueviolet)]()

## 简介

本 Skill 是一个基于 **Claude Code / Trae** 的周易占卜工具。它以《周易》六十四卦的卦象、卦辞、爻辞、五行生克为框架,结合 **梅花易数** 与 **六爻纳甲** 两大传统体系,为用户在当下情境下给出方向性的判断与可操作建议。

> **重要立场**:本 Skill 是「辅助思考 / 自我审视」工具,不是宿命论。涉及健康、法律、人生重大抉择时,请仍以专业意见(医师、律师、心理咨询师等)为准。

## ✨ 功能特性

- 🎴 **三种起卦法**:时间起卦 / 数字起卦 / 铜钱法
- 📜 **64 卦完整数据**:卦象、卦辞、六爻爻辞全覆盖
- 🧭 **六亲用神体系**:财运、姻缘、仕途、学业、健康、出行等分类取用神
- ⚖️ **体用 / 世应双体系**:融合梅花易数与六爻纳甲
- 🔥 **五行旺衰分析**:结合月令日辰判断用神强弱
- 📅 **应期推断**:近事断日时,远事断月年
- 📊 **七等吉凶分等**:大吉 / 中吉 / 小吉 / 平 / 小凶 / 中凶 / 大凶
- 💡 **可操作建议**:每次占卜输出 3~5 条具体行动建议

## 🚀 快速开始

### 1. 安装到 Claude Code / Trae

将本仓库克隆到本地 Skill 目录:

```bash
# Claude Code
git clone https://github.com/shaozhu520/zhou-yi-divination.git \
  ~/.claude/skills/zhou-yi-divination

# Trae (Windows)
git clone https://github.com/shaozhu520/zhou-yi-divination.git \
  %USERPROFILE%\.claude\skills\zhou-yi-divination
```

### 2. 触发 Skill

在 Claude Code 或 Trae 对话中,当你提出以下类型的问题时,Skill 会自动触发:

- "我想知道这件事该不该做 / 现在合不合适"
- "这次面试 / 跳槽 / 合作 /投资 结果会怎样"
- "我和某人的关系将如何发展"
- "接下来一段时间运势如何"
- "这件事的应期大概是什么时候"

### 3. 起卦流程

```
用户提问 → 澄清问题类别 → 选择起卦法 → 求本卦/之卦/动爻
        → 取卦辞/爻辞 → 定六亲用神 → 分析体用/世应/五行
        → 判定吉凶 → 推断应期 → 给出建议
```

## 📖 核心体系

| 体系 | 来源 | 核心思路 |
|------|------|----------|
| **梅花易数** | 邵雍 | 体用关系,动爻所在卦为用,另一卦为体 |
| **六爻纳甲** | 京房/野鹤老人 | 世应关系,六亲用神,月令日辰 |
| **五行生克** | 传统易学 | 木火土金水,旺相休囚死 |

### 六亲用神速查

| 占问 | 用神 |
|------|------|
| 求财(一般) | 妻财爻 |
| 求财(偏财/投机) | 官鬼爻 |
| 求官 / 升迁 / 求职 | 官鬼爻 |
| 求学 / 文书 / 考试 | 父母爻 |
| 婚姻(男占) | 妻财爻 |
| 婚姻(女占) | 官鬼爻 |
| 求子 / 健康 | 子孙爻 |
| 出行 / 远行 | 父母爻 + 世爻 |
| 谋事 / 一般 | 世应 |

## ⚠️ 适用范围

**适合**:
- 抉择类问题(该不该做、合不合适)
- 趋势类预测(面试/合作/投资结果)
- 关系走向(婚恋/合作/纠纷)
- 时机判断(何时行动最佳)

**不适合**(Skill 会婉拒或仅作文化分享):
- 求具体数字(如彩票选号)
- 询问他人隐私 / 离散事件地点
- 健康病症具体诊断
- 涉及伤害他人 / 违法的请求
