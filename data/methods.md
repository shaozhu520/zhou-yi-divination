## 一、起卦法

### 1.1 时间起卦（梅花易数，邵雍法）—— skill 默认

**先天八卦数（必须背）**：乾 1、兑 2、离 3、震 4、巽 5、坎 6、艮 7、坤 8
**地支序数**：子 1、丑 2、寅 3、卯 4、辰 5、巳 6、午 7、未 8、申 9、酉 10、戌 11、亥 12
**时辰划分**：子 23-1、丑 1-3、寅 3-5……亥 21-23（晚 23 点后算次日子时）

**核心公式**（年取**地支**数，月 / 日取**农历**数字）：

```
上卦 = (年支数 + 农历月 + 农历日)  mod 8
下卦 = (年支数 + 农历月 + 农历日 + 时支数)  mod 8
动爻 = (年支数 + 农历月 + 农历日 + 时支数)  mod 6
```

**余数规则**：
- 除 8 余 0 → 取 **8（坤）**
- 除 6 余 0 → 取 **6（第六爻动）**

**可执行算法**：

```
step1  lunar = 农历年月日时（年取地支数）
step2  sum1 = 年 + 月 + 日
step3  sum2 = 年 + 月 + 日 + 时
step4  上卦 = (sum1 % 8) or 8
step5  下卦 = (sum2 % 8) or 8
step6  动爻 = (sum2 % 6) or 6
step7  动爻所在位阴阳互换 → 得之卦
```

**注意事项**：
- 闰月：当作下一月，月数 +1。
- 若用户不记得农历月日，可用公历日期；skill 内部调用时按当下时间。

**验证案例**（邵雍《观梅占》）：辰年 5、十二月 17、申时 9
- 上卦 = (5+12+17) % 8 = 2 → **兑**
- 下卦 = (5+12+17+9) % 8 = 3 → **离**
- 动爻 = 43 % 6 = 1 → **初爻动**
- 本卦 = 泽火革；变卦 = 泽山咸

### 1.2 数字起卦（梅花易数法）

**两数起卦（最常用）**：
```
上卦 = 第一数 % 8（余 0 取 8）
下卦 = 第二数 % 8（余 0 取 8）
动爻 = (第一数 + 第二数) % 6（余 0 取 6）
```

**三数起卦（方法一）**：
```
上卦 = 第一数 % 8
下卦 = 第二数 % 8
动爻 = 第三数 % 6
```

**多位数字**：
- 三位数：百位→上卦、十位→下卦、个位→动爻
- 多位数（偶数位）：前段之和→上卦、后段之和→下卦、总和→动爻
- 多位数（奇数位）：前段比后段少一位（天轻地重），分别求上下卦与动爻

### 1.3 铜钱法（乾隆钱法，金钱卦）

**约定**（先定后不改）：
- **字面** = 阴（计 2）
- **背面** = 阳（计 3）

**每爻投三枚，共投六次**：

| 组合 | 合计 | 名称 | 性质 |
|------|------|------|------|
| 三背 | 9 | **老阳** | **动爻**（阳→阴）|
| 三字 | 6 | **老阴** | **动爻**（阴→阳）|
| 两背一字 | 8 | 少阴 | 静爻 |
| 一字两背 | 7 | 少阳 | 静爻 |

**口诀**：
```
背为阳，字为阴；
三背九 老阳动，三字六 老阴动；
两背一字少阴，一字两背少阳。
```

**步骤**：
1. 净手静心，默念所问之事（一事一卦）。
2. 三钱合掌摇动数下，掷于桌面。
3. 记录一爻；**自下而上**（第一次 = 初爻，第六次 = 上爻）。
4. 六次成形为本卦；老阳 / 老阴所在位阴阳互换得变卦。

### 1.4 揲蓍法（大衍筮法，朱熹整理）

> 用于知识完整性，操作繁复，多用于学术与仪式场合；skill 不强制执行。

- 取 50 根蓍草，留 1 不用，用 49 根。
- 每爻 = 「分二 → 挂一 → 揲四 → 归奇」三变完成，共需 18 变得一卦。
- 三变后剩余 36 / 32 / 28 / 24，分别对应 **老阳 9 / 少阴 8 / 少阳 7 / 老阴 6**。
- 画爻自下而上，老阳 / 老阴为动爻。

## 二、解读框架

### 2.1 本卦 / 之卦 / 互卦 / 错卦 / 综卦

| 卦名 | 推导 | 含义 |
|------|------|------|
| **本卦** | 起卦直接得出 | 当前状态、起点 |
| **之卦（变卦）** | 动爻阴阳互换 | 结局、终局 |
| **互卦** | 取 2-3-4 爻为下、3-4-5 爻为上 | 中间过程、暗流 |
| **错卦** | 六爻阴阳全反 | 对立面、相反处境 |
| **综卦** | 整卦上下翻转 | 对方视角、换位思考 |

**互卦推导口诀**：
```
互卦 = 上互（3、4、5 爻）+ 下互（2、3、4 爻）
即：去掉初爻与上爻，中间四爻上下各取三爻重叠。
```

**综卦小贴士**：八纯卦（乾、坤、坎、离、颐、大过、中孚、小过）无综卦（翻转后与自身一致）。

### 2.2 变爻取用规则（朱熹《易学启蒙》体例）

| 动爻数 | 取用 |
|--------|------|
| 0（六静）| 本卦卦辞 |
| 1 | 本卦动爻爻辞 |
| 2 | 本卦两动爻爻辞，**以上爻为主** |
| 3 | 本卦卦辞 + 变卦卦辞合参 |
| 4 | 变卦中两静爻爻辞，**以下爻为主** |
| 5 | 变卦中唯一静爻爻辞 |
| 6 | 变卦卦辞；乾用「用九」、坤用「用六」 |

**速记口诀**：
```
六爻不动看本卦辞，
一爻专看动爻家。
二爻动看上爻主，
三爻两卦并考察，
四爻五爻观静处，
六爻尽变看用卦。
```

### 2.3 世爻 / 应爻（纳甲六爻体系）

**八宫卦世爻定位口诀**：
```
天同二世，天变五，
地同四世，地变初，
本宫六世，三世异。
```

**解读**（阳卦四：乾、兑、离、震；阴卦四：巽、坎、艮、坤）：
- **天同二世**：上下卦同属阳 → 世在 **二爻**
- **天变五**：上卦阴、下卦阳 → 世在 **五爻**
- **地同四**：上下卦同属阴 → 世在 **四爻**
- **地变初**：上卦阳、下卦阴 → 世在 **初爻**
- **本宫六世**：八纯卦（乾兑离震巽坎艮坤）→ 世在 **六爻**
- **三世异**：上下卦既不同也不属阴阳变 → 世在 **三爻**

**应爻定位**：与世爻相隔两位（隔两位取对位）。
- 世初→应四；世二→应五；世三→应上爻；世四→应初；世五→应二；世六→应三。

> 注：skill 默认走梅花易数「体用」体系；仅在用户明确要六爻纳甲解读时才用世应。

### 2.4 用神 / 原神 / 忌神 / 仇神 / 泄神（六爻五行体系）

**总口诀**：
```
生用为原神，克用为忌神；
克彼原神者，仇神论；
用神所生者，泄神论。
```

**按占问类别取用神总览**：

| 占问类别 | 用神 | 原神 | 忌神 | 仇神 |
|---------|------|------|------|------|
| 求财（一般） | 妻财爻 | 子孙 | 兄弟 | 父母 |
| 求财（偏财/彩票） | 官鬼 | 妻财 | 子孙 | 兄弟 |
| 求官 / 升迁 / 求职 | 官鬼爻 | 妻财 | 子孙 | 兄弟 |
| 求学 / 文书 / 契约 | 父母爻 | 官鬼 | 妻财 | 子孙 |
| 婚姻（男占） | 妻财爻 | 子孙 | 兄弟 | 父母 |
| 婚姻（女占） | 官鬼爻 | 妻财 | 子孙 | 兄弟 |
| 求子 / 子女健康 | 子孙爻 | 父母 | 官鬼 | 妻财 |
| 求医 / 医药 | 子孙爻 | 父母 | 官鬼 | 妻财 |
| 自占疾病 | 世爻（自己）| — | 官鬼（病灶）| — |
| 出行 / 远行 | 父母爻（车船）+ 世爻 | — | — | — |
| 谋事 / 一般 | 世应 | — | — | — |
| 失物（一般） | 妻财爻 | — | — | — |
| 失物（文书证件） | 父母爻 | — | — | — |

**用神两现处理**：
- 一静一动 → 取动爻
- 两爻皆动 → 取旺相者
- 两爻皆静 → 取旺相或临世爻者
- 用神不上卦 → 查**伏神**（在本宫卦中取对应六亲伏于飞神之下）

### 2.5 应期（事件发生的时间）

**总原则**：
```
动则应速，静则应迟；生则应迟，冲则应速；合则应迟。
合待冲、冲待合、绝待生、墓待开、破待补、空待出旬、衰待旺。
远断年月，近断日时。
```

**爻位对应时间单位**：

| 爻位 | 时间尺度 |
|------|---------|
| 初爻 | 小时 / 日 |
| 二爻 | 日 |
| 三爻 | 旬 |
| 四爻 | 月 |
| 五爻 | 季 |
| 上爻 | 年 |

**常见应期规则**：

| 场景 | 应期 |
|------|------|
| 日辰临用神 / 生合世用 | **本日** |
| 用爻受克 | 制克之日 |
| 用神旬空发动 | 出旬之日；又逢日冲则本日 |
| 用神旺相受克 | 冲去忌神之日 |
| 用神休囚受克 | 忌神逢生之日（多为凶应）|
| 用神入墓 | 冲墓之日 |
| 用神发动 | 变爻所临地支之日 |
| 用神旬空 | 出空受克之日 |
| 用神伏藏 | 冲飞逢值之日 |
| 用神衰弱 | 旺相之月 |
| 卦遇六合 | 冲合之日 |
| 卦值六冲 | 逢合之日 |

## 三、吉凶分等

**判定公式**（野鹤老人《增删卜易》体例）：

```
吉凶 = 用神旺衰 × 原神 / 忌神状态 × 动变影响 × 事类喜忌
```

**七等判断依据**：

| 等第 | 卦象 / 用神条件 | 补充条件 |
|------|----------------|---------|
| **大吉** | 用神旺相 + 原神发动生扶 + 卦象吉 + 世用相生 | 变卦亦吉 |
| **中吉** | 用神旺相 + 原神得力 | 一两个有利条件 |
| **小吉** | 用神得位有气 + 忌神静 | 阻碍小 |
| **平** | 用神不旺不衰、忌神原神皆静、卦象中性 | 无明显吉凶 |
| **小凶** | 忌神发动 + 用神受克不重 | 世爻尚稳 |
| **中凶** | 忌神旺动 + 用神休囚 + 仇神助势 | 卦象偏凶 |
| **大凶** | 用神休囚被克 + 原神受伤 + 世爻受冲 | 变卦亦凶，或用神空破墓绝 |

**辅助判断要点**：
- **当位**：阳爻处阳位（初、三、五）、阴爻处阴位（二、四、上）为当位，吉利加分。
- **中正**：二、五爻分别为下卦、上卦中位，阴居二阳居五为「中且正」，大吉。
- **应期近远**：吉应近者力猛，远者力缓；凶应近者祸速，远者祸迟。
- **世应生克**：世克应→事在我，可成；应克世→事阻滞；世生应→我付出；应生世→他来益我。
