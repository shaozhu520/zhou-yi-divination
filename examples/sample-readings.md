## 示例一：求职面试（求官）

**问**：某工程师下周一去 A 公司面试技术总监职位，是否可成？

**起卦法**：时间起卦（公历 2026 年 10 月 8 日 14:30，农历丙午年九月十八未时）
- 丙午年 → 地支序 7（午）；九月 → 9；十八日 → 18；未时 → 8
- 上卦 = (7+9+18) % 8 = 34 % 8 = 2 → **兑**
- 下卦 = (7+9+18+8) % 8 = 42 % 8 = 2 → **兑**
- 动爻 = (7+9+18+8) % 6 = 42 % 6 = 0 → 取 6（第六爻动）

→ 本卦 **兑为泽**（☱☱），动爻六三（六三 → 老阴动，变九三）

### 之卦、互卦
- 六三阴变阳 → 之卦为 **兑卦对第三爻变阳**：
  - 兑 ☱☱ 6 爻全阴 → 三爻变阳 → 阳位爻位仍为阳 → 之卦 = 兑卦（阳位为阳爻）
  - 此处兑卦全阴变三爻一阳，整体仍是兑
  - 但更准确地说，兑卦六爻静阴，仅三爻一爻动 → 之卦即兑，三爻变阳
- 互卦 = 上互（3、4、5 爻）+ 下互（2、3、4 爻）
  - 兑 ☱☱ 自下而上：初六、九二、六三、九四、九五、上六
  - 上互 = 6,3,9 → 阴阴阳 → 离；下互 = 6,9,6 → 阴阳阴 → 震
  - 互卦 = **雷火丰**（??注：本算法细节略，实际解卦时互卦应正确取四爻组合）

### 卦辞与爻辞
> **兑卦卦辞**：兑，亨，利贞。
> **六三爻辞**：来兑，凶。

### 用神
求官 → 用神为 **官鬼爻**。兑卦属金，金克木 → 官鬼（木）受克 → 用神受克。
六三阴爻居阳位，不当位。

### 判断
- 卦辞「亨，利贞」指本卦总体可行；
- 但动爻六三爻辞「来兑，凶」，且不当位；
- 用神官鬼（木）受兑金之克卦（兑属金，金克木）；
- 综评：**小凶**，面试不利。建议延后或再准备，或考虑其他机会。

### 应期
- 六三动 → 应在第二爻所主「日」级别
- 近日内某日会有回音（面试反馈）

### 建议
1. 延后面试日期至金水月日（农历十月后）较为有利。
2. 面试前避免过于强调自己「来」（六三「来兑」之警示），改为「被动响应」。
3. 备选方案：可同时投递其他公司以分散风险。
4. 心态上：即便失败也无咎（卦辞曰「亨，利贞」）。

## 示例二：婚姻（女占）

**问**：某女士询问与现男友是否适合走入婚姻。

**起卦法**：时间起卦（公历 2026 年 10 月 5 日 21:00，农历丙午年九月十五戌时）
- 丙午年 → 7；九月 → 9；十五日 → 15；戌时 → 11
- 上卦 = (7+9+15) % 8 = 31 % 8 = 7 → **艮**
- 下卦 = (7+9+15+11) % 8 = 42 % 8 = 2 → **兑**
- 动爻 = 42 % 6 = 0 → 取 6

→ 本卦 **山泽损**（☶☱），动爻上九

### 之卦、互卦
- 上九阳变阴 → 之卦 = **山泽损 上九变阴**
  - 损卦自下而上：初九、九二、六三、六四、六五、上九
  - 上九变阴 → 之卦变为 **风山渐**（☴☶）—— 不对，应该是变为 **山泽损** 仅第六爻性质变
  - 简化：损六爻中仅上九一爻阳变阴 → 之卦就是本卦损，仅上九性质反
- 互卦 = 上互（3、4、5）= 六三、六四、六五 = 阴阴阳 = **离**；下互（2、3、4）= 九二、六三、六四 = 阳阴阴 = **震**
- 互卦 = **雷火丰**

### 卦辞与爻辞
> **损卦卦辞**：损，有孚，元吉，无咎。可贞，利有攸往。曷之用？二簋可用享。
> **上九爻辞**：弗损益之，无咎，贞吉，利有攸往，得臣无家。

### 用神
女占婚 → 用神 **官鬼爻**（木）。损卦上艮下兑，艮土兑金，土金组合克木 → 用神受克。

### 判断
- 卦辞"元吉，无咎"——大局吉；
- 上九爻辞"无咎，贞吉，利有攸往"——大方向可成；
- 但用神受克，需借"弗损益之"之道：双方都需付出，不要单方索取；
- 综评：**中吉偏小吉**，可成婚，但需彼此奉献。

### 应期
- 上爻动 → 应期偏长（年级别）
- 应期可定在秋季（农历九、十月，损卦应秋）

### 建议
1. 双方须有"弗损"之心——不计较个人得失，互补共同投入。
2. 婚期可选秋季（金旺，土旺之时，与卦象相合）。
3. 物质上应"二簋可用享"——不尚奢华，重真情。
4. 若对方家庭有阻碍（用神受克），则以诚信化解。

## 示例三：财运（求财）

**问**：某投资者想了解下季度某股票/项目是否值得投资。

**起卦法**：数字起卦。用户报数：228（财位），得到 2、2、8
- 上卦 = 2 % 8 = 2 → **兑**（金）
- 下卦 = 2 % 8 = 2 → **兑**（金）
- 动爻 = 8 % 6 = 2 → 第二爻动

→ 本卦 **兑为泽**（☱☱），动爻九二

### 之卦
- 九二阳变阴 → 之卦 = 兑卦第二爻变阴 → 之卦仍为兑
- 此例中兑卦全部为阴爻（初六、九二变阴后），整体从双兑变兑

### 卦辞与爻辞
> **兑卦卦辞**：兑，亨，利贞。
> **九二爻辞**：孚兑，吉，悔亡。

### 用神
求财（一般）→ 用神 **妻财爻**（木）。兑金克木 → 用神受克。但九二为阳爻居阴位（不当位）。

### 判断
- 卦辞「亨，利贞」——可投；
- 九二「孚兑，吉，悔亡」——诚信为本则吉；
- 但用神受克，需小心，财不可贪；
- 综评：**小吉偏平**，小进则止。

### 建议
1. 投资额宜小不宜大，"损上益下"——见好就收。
2. 不要借贷投资（用神受克之象）。
3. 选与"诚信"相关的标的（九二孚兑），避免炒作。
4. 周期控制在月内，不宜长持。
